# AGENTS.md

## Commands

All tooling runs through the Makefile-managed `venv/` (Python 3.12 hardcoded in the Makefile). Run `make venv` first if it's missing; don't use bare `pip`/`python`.

- `make format` — pre-commit run -a (CI gate on every push). **Always run it after making any edits** (repo owner requirement).
- `make test` — pytest with `-x` and coverage over `src/`
- Single test: `venv/bin/pytest tests/dbal/test_dbal.py -k <name>`
- `make tox` — full matrix py312/py313/py314 (`tox --parallel`). **Always run it before committing** to test across interpreter versions (repo owner requirement).
- `make build` — clean + sdist/wheel via `python -m build`

There is no mypy/typecheck step; linting = pre-commit only. CI (.github/workflows/testing.yaml) runs format, test, tox, build on every push.

## Style rules that differ from defaults (enforced by pre-commit)

- **One symbol per import line**: `from x import a` + `from x import b`, never `from x import a, b` (reorder-python-imports).
- **Single quotes** for strings (black has `skip-string-normalization` + double-quote-string-fixer converts doubles to singles).
- Line length is **100**, not 88.
- **docsig is strict**: every function/method/class docstring must document all args/returns in Sphinx style or CI fails. Run `make format` before pushing.

## Architecture

Small src-layout library, package `spilli_dbal` (PyPI name Spilli-DBAL): framework-independent CRUD/pagination over SQLAlchemy 2 + marshmallow 4. Public API is re-exported from `src/spilli_dbal/__init__.py`:

- `dbal/sqla.py` — `SqlaDBAL[Model]`: CRUD/bulk methods; translates SQLAlchemy errors into typed exceptions from `dbal/exceptions.py`
- `statement_maker.py` — `StatementMaker`: builds select statements (where/order_by/limit/offset)
- `models/base.py` — `ModelMixin` for declarative models (UUID PK); `models/fields.py` — e.g. `UTCDateTime`
- `schemas/` — marshmallow base schema + pagination dump schemas

## Testing quirks

Tests need no external services — in-memory SQLite (`sqlite://`). Fixtures in `tests/conftest.py` define models (`Parents`/`Children`/`Fathers`) dynamically and are **session-scoped**: DB rows persist across tests, so tests share state (unique-name generator prevents collisions). Don't convert them to function-scoped casually.
